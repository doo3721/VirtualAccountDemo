테스트 입금 및 알림 확인

PortOne 콘솔의 해당 테스트 결제에서 테스트 입금 통지를 실행한 후, 위 버튼으로 상태를 조회하세요. 이 통지만으로 토스페이먼츠 웹훅 발송까지 검증되지는 않습니다.

입금 알림은 토스페이먼츠 → PortOne → 데모 서버 순서입니다. 이 앱의 수신 주소는 PortOne 콘솔의 V2 테스트 웹훅에 https://공개주소/webhooks/portone으로 등록하세요. localhost 주소는 외부에서 접근할 수 없습니다. 웹훅 수신 후 화면을 새로고침하면 갱신된 상태가 표시됩니다.

토스페이먼츠에서 시작하는 입금 이벤트는 토스페이먼츠 개발자센터의 해당 MID 테스트 결제내역에서 확인하세요. 테스트 계좌에는 실제 송금할 수 없습니다.

모든 일시는 한국시간(Asia/Seoul)입니다.
